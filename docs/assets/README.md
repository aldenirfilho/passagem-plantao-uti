# Imagens do Passagem UTI v5

## Conceitos

Arquivos em `concepts/` são explorações visuais geradas para comunicar a direção do produto. Usam placeholders DEMO, avatares abstratos e selo incorporado **CONCEITO FUTURO · DADOS FICTÍCIOS**. Podem mostrar recursos planejados. Não são prova de implementação nem devem ser usados como evidência regulatória.

- `cockpit-plantonista-v5.png`: visão proposta do plantonista vigente e dos dez leitos.
- `central-coordenador-v5.png`: visão futura do coordenador institucional.
- `capsula-uti-v5.png`: fluxo conceitual de continuidade e canais de exportação.

## Capturas verificadas

Arquivos em `screenshots/` são capturas reais da versão candidata, realizadas localmente com dados sintéticos depois dos testes. Cada release deve substituir as capturas quando a interface mudar materialmente.

- `app-v5-light.webp`: cockpit real no tema claro.
- `app-v5-dark.webp`: cockpit real no tema escuro.
- `app-v5-opportunities.webp`: oportunidades e coordenação local.
- `app-v5-transfer.webp`: central de transferência e Cápsula UTI.
- `app-v5-mobile.webp`: viewport móvel.

Os PNGs de QA podem permanecer no workspace de desenvolvimento, mas o pacote de release usa as versões WebP otimizadas.

## Regra de privacidade

Somente dados sintéticos podem aparecer nestas imagens. Não inserir nome, prontuário, exame, hospital, CRM real, chave, URL assinada ou outro identificador de produção.
